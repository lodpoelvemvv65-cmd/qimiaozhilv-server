# 抓包归档

此目录统一保存协议分析抓包，禁止把 `.pcap` 或 `.pcapng` 放在工作区根目录、
`server-mysql/` 或协议实测脚本目录。

## 内容

- `online-*.pcapng`：从线上服务器抓到的协议样本（本文档中「线上抓包」的证据来源）。
- `local-*.pcapng`：本地自建服的抓包，**全部 0 帧**（`pktmon` 抓不到本机自连，见
  `文档/39-抓包工具链与归档位置-2026-09-18.md` §1.1），仅作反例留档。
- `*.txt`：人工整理的时间线/字段解读。
- `*.jsonl`：`tools/_pcap_frames.py` 逐帧解出的协议帧，是分析脚本的实际输入。

## 匿名化说明

为保护抓包机器的网络信息，本目录内的抓包**已做原地匿名化**：

| 项 | 处理 |
|---|---|
| 抓包机器的内网 IP | 统一改写为 `192.168.1.100` |
| 抓包机器的 TAP/虚拟网卡地址 | 统一改写为 `10.8.0.100` |
| 线上服务器地址 | 保留原值 `101.43.6.155` |

改写只替换 IPv4 头里的地址字段，并**重算 IP 头校验和与 TCP/UDP 校验和**；
pcapng 的块结构、文件长度、帧时序、帧数与载荷长度均未改变。

## 未随仓库发布的内容

- **`.etl` 原始跟踪文件**：Windows `pktmon` 的 ETW 格式，无法安全匿名化，因此不随仓库发布。
  如需原始跟踪，请自行用 `tools/capture_traffic.ps1` 重新抓取。
- **早期混杂流量样本**：2026-08-13 的一次全系统抓包含大量与协议无关的流量（DNS、CDN 等），
  不具备归档价值，已从仓库移除。

新增抓包应使用能说明日期和用途的文件名，并在相关协议文档中引用此目录下的相对路径。
新抓包入库前请先做同样的匿名化处理。
