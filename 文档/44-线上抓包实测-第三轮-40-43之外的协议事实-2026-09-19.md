## 1. ★★ `20077 M2C_PlaySkillEffect` —— 整条"战斗表现层"通道

**单流 716 帧 / 全包 3580 帧**，与 `20169`（3580 帧）并列本包最大的两条消息，
排在 `20080`(2850)、`20078`(2795)、`20170`(2660)、`20075`(1490) 之前。
**`文档/39~43` 一次都没提过它。**

字段（`参考数据/protocol_dump.txt`）：

```
[1] UnitId            [4] TargetId        [6] Time
[8] EffectPos         [9] EffectId        [10] EffectTargetType
```

### 1.1 核心语义：`Time` 由效果类型决定，不能统一解释为弹道飞行时长

```
t=77.48  22233 施法 210603（开大脚，走 20075）
t=78.49  20077 {1:22233, 4:BOSS, 9:2232, 6:1000}   ← 释放，飞行 1.0s
t=79.49  20077 {1:22233, 4:BOSS, 9:2233}           ← 命中
```

对 `2232 → 2233` 这类投射物，`Time=1000` 确实对应释放到命中的飞行延迟；一批其它投射效果也呈现相邻 EffectId：

```
2232 → 2233    2214 → 2215    2209 → 2210    2201 → 2202
3009 → 3010    3013 → 3014    3015 → 3016    3019 → 3020
2127 → 2128    2401 → 2402    2301 → 2302    2426 / 2427 / 2430 / 2431
```

`Time` 取值分布（单流 716 帧）：

| Time | 帧数 | 含义 |
|------|------|------|
| 缺省 | 413 | 无持续/飞行时间；在成对投射物里通常是命中效果 |
| 1000 | 174 | 在 `2232 → 2233` 等配对里是 1.0s 弹道飞行时间 |
| 14000 | 60 | 14s 效果或表现持续时间，不是 14s 弹道 |
| 21000 | 37 | 护盾类 21s 持续表现，不是弹道 |
| 11000 | 14 | 11s 效果/表现持续时间 |
| 10000 | 8 | 10s 效果/表现持续时间 |
| 7000 | 7 | 7s 效果/表现持续时间 |
| 5000 | 3 | 5s 效果/表现持续时间 |

`[8] EffectPos`：缺省 676 帧、`1` 40 帧。

### 1.2 为什么它重要

1. **它解释了"为什么部分反击/普攻不发 `20075`/`20076`"**（见 `文档/34` 的反击结论）——
   投射型效果可只用 `20077` 的释放/命中表现，不需要额外施法帧；不能推广为每个技能都有两帧；
2. **它是唯一能看见"效果打在谁身上"的通道**：
   `20075` 只有（施法者, 技能ID）、`20078` 只有（被打者, 血量变化）、`20080` 只有（目标, 图标, 时长），
   **只有 `20077` 同时给出（施法者, 目标, 效果ID, 上下文相关的 Time）**；
3. **BOSS 也发 `20077`**（单流 146 帧）：`3015/3016 → 22240`、`3013/3014 → 22234`、
   `3019/3020 → 22233`、`2222 → 18937`、`3028 → 自己`；
4. 它同时也是 `文档/43` §2④「叠层清零条件」的证据来源（**该结论已就地写入 43，本文不重复**）。

### 1.3 服务端现状

服务端**已经在发** `M2C_PlaySkillEffect`（`battle_actions.go:417`、`battle_skill_events.go:85`），
但还需按具体 `EffectId` 核对：投射类的 `Time` 是否等于飞行时间、持续类是否等于状态/表现时长、
哪些效果需要 `X/X+1` 两帧。**不能把一套规则套到全部 `20077`。**

### 1.4 `20075` 字段边界（2026-09-19 修复）

全包 1490 帧 `20075 M2C_PlaySkill` 均只有 tag 1 `UnitId` 与 tag 2 `SkillId`。
服务端此前额外填写 `CoolTime/TargetId/MpCost`；现已在即时玩家施法、队伍排队和旧兼容路径全部删除，
由 `20237` 独立承载公共间隔与技能 CD。提交 `c2e0268`，wire tag 回归与字段职责见 `文档/49`。
