# 06 — 登录协议与消息清单

> 本文档基于 `参考数据/protocol.proto`（429 条消息、13 枚举）、`protocol_dump.txt`。
> opcode 与字段 tag 均已从 Hotfix.dll 反汇编提取。

## 1. 登录链路总览

```
客户端                         网关 (Realm/Login 服)
  |-- C2R_Login(20008) --------->|  账号+密码
  |<-- R2C_Login(20009) ---------|  返回 Key + 网关(Gate) 地址
  |
  |  —— 重新建连到 Gate 地址 ——
  |-- SYN/ACK 握手（02 文档）---|
  |-- C2G_LoginGate(20014) ----->|  Key + GateId
  |<-- G2C_LoginGate(20015) -----|  PlayerId + HasRole + JobId + ServerTime + SkinId
  |-- C2G_EnterGame(20027) ----->|  进入游戏
  |<-- G2C_EnterGame(20028) -----|  Id + SkinId + JobId + IsOnline
  |-- C2G_HeartBeat(20012) ----->|  心跳
  |<-- G2C_HeartBeat(20013) -----|  DelayTime + Key
```

### 注册与角色

| opcode | 消息 | 关键字段 |
|--------|------|----------|
| 20010 | C2R_Regist | Account=1, Password=2, Identify=4, RpcId=90 |
| 20011 | R2C_Regist | 同 R2C_Login（Address/Key/GateId/LoginVoucher） |
| 20016 | C2R_CreateRole | PlayerId=1(i64), JobId=2(i32), Name=3, RpcId=90 |
| 20017 | R2C_CreateRole | 仅 RpcId/Error/Message |
| 20018 | C2R_DelRole | UserId=1(i64), RpcId=90 |
| 20019 | R2C_DelRole | 仅 RpcId/Error/Message |

注册界面资源 `Login_fui` 明确显示账号“由数字字母组成”、密码“由 6~16 位数字字母组成”；但
`FUI_RegisterAwakeSystem.<Start>b__1` 会直接调用 `LoginHelper.OnRegistAsync(account, password)`，
客户端没有执行格式校验。因此当前服务端在写入 MySQL 前权威校验：账号仅允许 ASCII 数字/字母，
密码仅允许 6-16 位 ASCII 数字/字母。空账号、空密码、账号格式、密码格式和重复账号分别返回
`Error=200003/200004/200005/200006/200008`，`Message` 使用 `Sys_Code` 的原版中文提示。
这些错误均大于 `200000`，会进入 `LoginHelper` 的 `ShowTipUI` 分支；校验失败不会创建账号。

## 3. RpcId 配对机制（RPC 请求-响应）

- **RpcId 是 protobuf 字段（tag=90，int32），随 body 序列化**，不是独立线前缀（03 文档更正）。
- 客户端 `Session.Call(req)`：分配自增 `RpcId` 写入 req，存入 `requestCallbacks[RpcId]`。
- 服务器处理请求后回响应消息：`resp.RpcId = req.RpcId` 原样回填，`Session.Send(resp)`。
- 客户端 `Session.OnRead(resp)`：`requestCallbacks.TryGetValue(resp.RpcId)` 命中 →
  `Remove(RpcId)` → 按 `resp.Error`（tag=91）判断成功/异常，`Tcs.SetResult/SetException`。
- **服务器必须回填 RpcId**，否则客户端永远等不到响应（超时 2000ms 后报错）。
- Error!=0 时客户端按 `IsRpcNeedThrowException` 决定抛异常或静默返回（用于可预期失败）。

## 5. 登录流程服务器实现要点（Go）

1. 收 `C2R_Login`：校验账号密码（自建库），生成 `Key`（int64）并记录，返回
   `R2C_Login{ Address: 自建网关地址, Key, GateId, LoginVoucher }`，**回填 RpcId**。
2. 客户端按 Address 重连到网关端口（实际实现 = 同一 TCP 端口 7756，登录/网关同端口按消息区分）。
3. 收 `C2G_LoginGate`：校验 `Key` 是否由本服签发、`GateId` 匹配，创建玩家会话，
   返回 `G2C_LoginGate{ PlayerId, HasRole, JobId, ServerTime, SkinId }`。
4. 收 `C2G_EnterGame`：确认角色就绪，返回 `G2C_EnterGame{ Id, SkinId, JobId, IsOnline }`。
5. 心跳 `C2G_HeartBeat` → `G2C_HeartBeat{ DelayTime, Key }` 维持连接。
6. 所有响应一律 `RpcId` 原样回填；错误走 `Error` 字段 + 非零退出（具体错误码由业务定）。
