## 3. 修复后行为

### 3.1 PvE 状态概率与抗性

线上样本中五名玩家仅装备直接 Res 已有 130~170，`500041` 的 95% 眩晕仍命中 30/33。修复后的参与矩阵为：

| 模式 | 状态成功率 |
|---|---|
| PvE 玩家 → 怪物 | 直接使用配置概率 |
| PvE 怪物 → 玩家 | 直接使用配置概率 |
| PvP 玩家 → 玩家 | `configured × (100 + Hit) / (100 + Res)`，再夹到 0~100% |
| PvE 怪物直接伤害 | 保持必定命中；不与状态概率复用判定函数 |

这项修复不代表 Res 属性无效；它只取消本包已经反证的 PvE 状态对抗用途。PvP 仍保留，PvP 公式仍需线上样本验证。

### 3.2 家族 BOSS 全阶开场属性

统一公式为：

```text
开场倍率 = Gameplay.family_boss.attribute_base_multiplier + FamilyBossConfig.CharacterAdd
当前基值 = 1.20
```

| 阶 | CharacterAdd | 开场倍率 | 证据等级 |
|---:|---:|---:|---|
| 1 | 0.05 | 1.25 | 指定公式推导，未抓包 |
| 2 | 0.08 | 1.28 | 指定公式推导，未抓包 |
| 3 | 0.15 | 1.35 | 指定公式推导，未抓包 |
| 4 | 0.23 | 1.43 | 指定公式推导，未抓包 |
| 5 | 0.33 | 1.53 | 线上抓包直接实测 |

| 类别 | NumericType | 修复后 |
|---|---|---|
| 当前/最大 HP | 1001~1002 | 不缩放 |
| 双攻、双防 | 1009~1012 | `MonsterBase × 当前阶开场倍率` |
| 双暴击率/值、辅助、四项抗暴 | 1013~1021 | `MonsterBase × 当前阶开场倍率` |
| 物理/精神免伤 | 1022~1023 | 不缩放 |

当前自建服开场在 `20144` 或队员重发 `20145` 后发送一帧 17 项 `20170`，顺序为 `1001,1002,1009..1023`。这句话描述的是**服务端当前实现和本地测试**，不是线上本包的包序：线上本包 `20144/20145` 均为 0 帧，实际观察到 `20139→20141`、`20142→20143` 后直接推 17 项 `20170`。由于本包不含登录和最初进图，暂不能删除 `20144/20145`，需用完整链路确认其是否仅用于进图、重连或状态恢复。
整数属性采用 Round；五阶精神防御为 `Round(1689811×1.53)=2585411`。

### 3.3 4.71 秒属性叠层

运营配置：

```yaml
family_boss:
  attribute_base_multiplier: 1.20
  attribute_stack_interval_ms: 4710
```

所有阶只有双攻双防 `1009~1012` 按共享时间网格推进；`1013~1021` 只吃开场倍率，不参与 tick：

```text
B_a = Round(MonsterBase_a × (1.20 + CharacterAdd))
V_a = B_a × (1 + CharacterAdd × n_a + 属性 a 的外部百分比修正)
```

- 每到一个 4710ms 网格点，四项各自 `n_a+1`；各阶每层分别增加 `5%/8%/15%/23%/33%`。
- 不设置 14 层硬上限；抓包最高只观察到 14 层，不能据此推导上限。
- 外部百分比修正首次施加、确实新增效果层、移除或到期时，只清它实际修改属性的 `n_a`。
- 同一效果在活跃期刷新只延长持续时间，不清零。
- 队伍成员共享一个 runtime 状态，同一时刻多个 runtime `Tick` 只推进一次。
- 每个纯 tick 增量 `20170` 只含 `1009,1010,1011,1012` 四项。
- BOSS 不发送玩家状态图标协议 `20080`。

### 3.4 周期中毒节拍

客户端效果树复核纠正了文档中的 modifier 层级：

```text
50001035  外层 modifier
└─ 50001033  event 8 周期中毒节点（实际进入 applyPeriodic）
```

因此热加载配置按实际节点填写：

```yaml
combat:
  effect_tick_interval_ms: 4000
  periodic_tick_overrides_ms:
    "50001033": 3500
```

只对该中毒使用 3500ms；HOT 和其它未获独立抓包证据的周期效果仍使用 4000ms。流血、点燃不能从这一个样本外推。
