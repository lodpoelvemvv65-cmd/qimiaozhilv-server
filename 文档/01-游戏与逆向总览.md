# 01 — 游戏与逆向总览

## 1. 游戏基本信息

- **游戏**：《梦幻奇遇记》（太空射击类）
- **引擎**：Unity **2020.3.49f1**
- **脚本后端**：**Mono**（非 IL2CPP）→ 程序集为可反汇编的 .NET DLL，**未混淆**
- **网络框架**：**ET 框架**（开源 C# 游戏服务端框架）。⚠ 早期分析以为是 KCP/UDP；
  反汇编实证客户端创建 **TService（TCP）**（`NetKcpComponentAwakeSystem.Awake` Rva=0xE17C
  `newobj ET.TService::.ctor`）。KService/KChannel 类虽在程序集内但未使用。帧 =
  `[u16 LE 总长度][u16 LE opcode][protobuf body]`，见 `server/tcp_srv.go`。

## 6. 网络总体架构（还原结论）

```
客户端(Unity, Mono)
  └─ NetKcpComponent ── AService(KService) ── UDP Socket :xxxxx
        │   KChannel(Connect, 主动连)              │  SendTo 127.0.0.1:7756
        └─ KCP (kcp.dll P/Invoke)                  ▼
                                         ┌───────────────────┐
                                         │  自建服务器 (Go)    │
                                         │  UDP :7756         │
                                         └───────────────────┘
```

- **ServiceType**：Outer=0（客户端对外通信），Inner=1（服务器内部通信）
- **ChannelType**：Connect=0（主动连接方），Accept=1（被动接受方）
- 客户端对外只使用 **Outer(ServiceType=0)** 通道连网关；登录返回的 Gate 地址仍走 Outer。
