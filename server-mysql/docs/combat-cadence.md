# 战斗时序规则（2026-09-10）

本页记录用户确认的本地 PvE 规则，不作为原版抓包结论。

- 自动模式：开场第 5 秒出手，随后按固定 6 秒回合行动。一个队伍只认领一次怪物回合，并在同一批次接受所有可行动自动角色的技能。轮询只唤醒共同调度，不单独补打技能。
- 手动模式：开场即可攻击；成功出手后独立等待完整 6 秒，冷却结束后可以随时攻击。怪物时钟不会移动人物冷却，也不为手动点击排队。
- 自动切手动：保留上一次出手的剩余冷却。手动切自动：保留冷却，加入冷却结束后的第一个未来怪物回合。自动期间拒绝快捷栏手动技能请求。
- 攻击：先出手，统一前摇后发射，同一批次的弹道采用共同飞行时长，在一个命中回调内结算双方伤害并广播血量。出手时只扣资源、记录冷却，不预先扣目标血量。
- 无弹道治疗、增益立即生效，不等待怪物弹道。技能目标范围、命中、暴击、独立技能 CD、资源与控制条件仍按配置执行；同频不保证每个人每轮都能成功施法。
- 发射前已死亡或不能施法的单位取消发射；已发射攻击不因来源死亡取消。最后一个怪物死亡后，必须等在途攻击完成再判断胜负；双方都倒下沿用失败优先规则。
- 强制退出、换战斗或断线使旧回调失效，同时释放在途计数，避免剩余队员卡在等待结算状态。

关键代码：`battle_round.go`、`battle_monster_attack.go`、`battle_skill_runtime.go`、`battle_speed.go`、`auto_battle.go`。

日志 `[combat.attack]` 包含同一批次 `wave`、战斗 `battle`、施法者、目标、技能、阶段、原因和纳秒时间戳。与 `[combat.damage]` 的前后血量一起核对发射和命中。

回归：`go test ./...`；关键场景在 `battle_round_test.go`，包含五人共同批次、连续回合不漂移、模式切换、治疗即时生效、最后一个怪物在途伤害和双方致命一击。

学习新技能同时消耗一个技能点及 `SkillLearn[技能ID×100+0]` 配置的技能书，升级消耗当前等级行的书。材料不足不扣技能点或部分材料；付费重置按已学等级返还配置材料，免费重置不返还材料。
